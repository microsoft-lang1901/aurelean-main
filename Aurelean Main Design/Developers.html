# Create an RFQ across verified mills

  -H "Authorization: Bearer $AURELEAN_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "material": "super-150s-worsted-wool",
    "quantity_m": 120,
    "target": "2026-Q3",
    "mills": ["cerruti", "barberis", "drago"]
  }'
import { Aurelean } from "@aurelean/sdk";

const ar = new Aurelean(process.env.AURELEAN_KEY);

const rfq = await ar.rfqs.create({
  material: "super-150s-worsted-wool",
  quantityM: 120,
  target: "2026-Q3",
  mills: ["cerruti", "barberis"],
});

Quickstart

Your first request in three steps.

1

Get your API key

Request access and generate a key from your workspace settings. Keys are scoped per environment.

AURELEAN_KEY=sk_live_•••••
2

Install the SDK

First-class SDKs for Node and Python, with typed resources and helpers for every endpoint.

npm i @aurelean/sdk
3

Make a call

Authenticate, then search suppliers, issue RFQs, or query operational memory.

ar.suppliers.search({ fiber: "wool" })

Suppliers

Discover and evaluate verified mills, makers, and ateliers — with intelligence on capability, capacity, and provenance.

GET/v1/suppliersList & filter suppliers
GET/v1/suppliers/{id}Retrieve a supplier
POST/v1/suppliers/searchIntelligence-led search

RFQs & Bids

Issue structured requests for quotation, orchestrate responses, and compare bids programmatically.

POST/v1/rfqsCreate an RFQ
GET/v1/rfqs/{id}/bidsList bids on an RFQ
PATCH/v1/bids/{id}Award or decline a bid
DEL/v1/rfqs/{id}Withdraw a draft RFQ

Operational Memory

Query the long-context memory of decisions, specs, and supplier interactions across your operation.

POST/v1/memory/querySemantic memory search
GET/v1/memory/{thread}Retrieve a memory thread
POST/v1/webhooksSubscribe to events
